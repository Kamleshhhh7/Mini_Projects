# KNN Regressor From Scratch

## About the Project

This is a small machine learning project I created while learning how the K-Nearest Neighbors algorithm works for regression problems.

Instead of directly using a ready-made KNN regression implementation, I implemented the basic logic myself to understand what happens behind the scenes when the algorithm makes a prediction.

The project focuses on understanding how distances are calculated, how the nearest data points are selected, and how their values are used to make a prediction.

## What I Practiced

- Loading and exploring a dataset
- Preparing features and target values
- Train-test splitting
- Understanding KNN regression
- Calculating distances between data points
- Finding the nearest neighbors
- Using neighboring values to make predictions
- Evaluating regression predictions
- Implementing an algorithm from scratch

## Algorithm Used

### K-Nearest Neighbors Regression

KNN Regression makes a prediction by finding the data points that are closest to a given input and using their target values to calculate the predicted result.

For this project, I implemented the basic KNN regression logic from scratch to understand the working of the algorithm instead of relying completely on a pre-built implementation.

## Dataset

The project uses the dataset loaded within the Jupyter Notebook.

The data is used to train and test the KNN regression implementation.

## What I Learned

This project helped me understand how KNN regression works internally.

It also helped me understand how a machine learning algorithm can be broken down into smaller mathematical and logical steps instead of treating it as a black box.
