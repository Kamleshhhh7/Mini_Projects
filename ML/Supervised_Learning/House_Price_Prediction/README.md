# House Price Prediction

## About the Project

This is one of my early supervised learning projects, created while learning the basics of machine learning.

The goal of this project is to predict house prices using the features available in the dataset. I used Linear Regression and went through the basic machine learning workflow, from understanding and preparing the data to training and evaluating the model.

I also experimented with feature scaling to see how it affects the model's performance.

## What I Practiced

- Loading a dataset using Pandas
- Exploring the dataset
- Understanding different features
- Handling categorical data
- Data preprocessing
- Train-test split
- Linear Regression
- Model prediction
- Model evaluation
- Feature scaling
