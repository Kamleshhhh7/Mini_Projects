# Iris Flower Classification

## About the Project

This is one of my early supervised learning projects, created while learning the basics of machine learning classification.

The goal of this project is to classify iris flowers into their respective species using measurements such as sepal length, sepal width, petal length, and petal width.

I experimented with multiple classification algorithms and compared their performance to understand how different models approach the same classification problem.

## What I Practiced

- Loading and exploring data using Pandas
- Understanding features and target variables
- Encoding categorical target values
- Splitting data into training and testing sets
- Training classification models
- Making predictions
- Evaluating model performance
- Comparing different classification algorithms

## Models Used

### Logistic Regression

Logistic Regression was used to classify iris flowers into their respective species.

### K-Nearest Neighbors (KNN)

KNN was used to classify flowers based on the similarity between their feature values and nearby data points.

### Gaussian Naive Bayes

Gaussian Naive Bayes was also used as another classification approach and its performance was compared with the other models.

## Model Evaluation

The models were evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report

The results were compared to understand how the different models performed on the test data.

## Dataset

The project uses `Iris.csv`.

The dataset contains measurements of iris flowers, including:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable represents the species of the flower.
