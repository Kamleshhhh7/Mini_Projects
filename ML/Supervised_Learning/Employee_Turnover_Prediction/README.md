# Employee Turnover Prediction

## About the Project

This is one of my early supervised learning projects, created while learning how machine learning can be applied to classification problems.

The goal of this project is to predict whether an employee is likely to leave an organization based on different employee-related factors.

I followed the basic machine learning workflow, starting with understanding and preparing the data, then training a classification model and evaluating its predictions.

## What I Practiced

- Loading and exploring data using Pandas
- Understanding the dataset and its features
- Data preprocessing
- Handling categorical variables
- Splitting data into training and testing sets
- Training a classification model
- Making predictions
- Evaluating model performance
