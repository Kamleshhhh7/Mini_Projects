# Shop Smart

## About the Project

This is a supervised learning project I created while learning how machine learning can be applied to e-commerce data.

The goal of this project is to use customer and shopping-related information to build a machine learning model that can make predictions based on the patterns present in the dataset.

This project helped me practice the complete machine learning workflow, from understanding and preparing the data to training a model and evaluating its predictions.

## What I Practiced

- Loading data using Pandas
- Exploring the dataset
- Understanding customer and shopping-related features
- Data preprocessing
- Selecting features and target variables
- Train-test splitting
- Machine learning model training
- Making predictions
- Evaluating model performance

## Model Used

The project uses a supervised machine learning model to learn patterns from the e-commerce data and make predictions.

The model was trained using the prepared training data and then evaluated using the test data.

## Dataset

The project uses `shop_smart_ecommerce.csv`.

The dataset contains e-commerce-related information about customers and their shopping activity.

The available features are used to understand customer behaviour and build the machine learning model.
